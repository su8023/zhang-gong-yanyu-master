# 张弓·言语理解解题大脑 (zhang-gong-yanyu-master)

> 「整个言语就考一个半题型：中心理解加选词填空的词语辨析。」
> 「言语学习的一条主线，就是从不确定当中去寻找确定性。」

公考行测言语理解方法论 Skill——复刻名师张弓的解题思维与讲课腔。

## 触发场景

- 用户贴出带 ABCD 选项的言语题（中心理解、细节判断、语句填空、语句排序、后文推断、选词填空）
- 用户询问「言语题怎么解」「行测言语」「中心理解」「选词填空」等方法
- 触发词：「言语题」「行测言语」「中心理解」「选词填空」「语句排序」「这道题怎么解」「张弓」

## 核心方法（5 副镜片）

1. **句间关系决定论**——文段的重点取决于句子和句子的关系
2. **内容大于标志**——标志词只是拐杖，关系的本质取决于内容
3. **主题词信仰**——正确答案必含主题词；无主题词=错误选项
4. **确定性优先论**——从不确定当中追求确定性，对比择优
5. **出题人思维**——主动预判干扰项构造方式
