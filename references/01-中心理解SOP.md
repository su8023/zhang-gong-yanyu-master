# 中心理解 + 细节判断 SOP（张弓方法）

## §一 中心理解三步走

### 总框架
> 「中心理解的解题思路一定要记住是三步走：第一步寻找重点中心，第二步同义替换，第三步选项排除。」
> 做题顺序「二一三」：先读提问方式（定题型）→ 再读文段 → 最后看选项。「一定不能先看文段。」
> 实际操作中二三常一起做：边同义替换边排除。

### 第一步：找重点中心句 —— 七大关系判位置

> 「文段的重点取决于句子和句子的关系。」逐句读，每句问：这句和前面是什么关系？

| 关系 | 判定标准 | 重点位置 |
|---|---|---|
| **解释** | 后文没脱离前文话题，围绕前文展开/论证/举例/详述（本质=话题没变）。有无标志均可 | 被解释的观点是重点：「解释不重要，被解释的才是重点」。观点在前简略，解释在后详细 |
| **新旧** | 后文不是解释前文（「不是解释」即新旧），出现新话题/新观点/新时间/新做法 | 新比旧重要。「只要跟前面话题有些区别的统称为新的」 |
| **强调** | 程度词引导（更/尤其/特别/最/甚至/核心/正是/值得注意…），「读完明显感觉语气越来越重」 | 程度词强调的是重点，强调之前的内容一般不重要。「没有白来的强调」 |
| **转折** | 后文反驳前文（全部或部分推翻）。标志：虽然/但是/然而/却/其实/事实上… 无标志也可判（内容相反） | 「转折之后是重点，转折之前不重要，这是我们的考点。」多转折取最后的落脚点 |
| **因果** | 结论对前文总结概括。标志：因此/所以/可见/总之/换句话说/有鉴于此… | 「结论之后是重点，结论之前不重要。」尾句出现结论词，尾句是中心句概率高达80% |
| **对策** | 出现做法或问题即对策类文段。引导词：应该/需要/必须/只有才/亟待/不妨… | 「文段但凡出现对策，它就是最重要的。」对策＞意义效果。对策看内容不看形式 |
| **并列** | 无转折无结论无对策无程度加强的「平整」文段；标志：此外/同时/分号/排比句式/时间序列 | 无重点=全面概括。只有并列才需要选全面，其余题型只强调重点 |

**细则补丁**：
- 「其实/事实上/实际上」不一定转折，本质看内容。
- 「比如」不能直接跳读，要确认例子到哪为止；对例子的总结依然是例子。
- 转折本质也是新旧；七关系不互斥，「你中有我我中有你」。
- 开头「A怎么样，B也怎么样」→ 重点是B（定律，必须在开头）。
- 下定义一般不重要（经验之谈非绝对）。
- 背景句若被全文围绕也可做中心句。
- 一个引导词只管它所在的句子，不一定管辖全文。
- 根据非重点反推重点：例子围绕谁举，谁就是重点。

### 第二步：同义替换 —— 抓主题词

**主题词**：文段围绕的核心话题 = 核心动名词（「是谁呀」+「怎么了/怎么办」）。
**三找法**：①中心句围绕的核心动名词（最主要）②高频词 ③首句引出的话题。「以一为主，结合二三。」
**定理**：正确答案必含主题词；无主题词 = 错误选项，直接干掉，不需要太多费口舌。
**操作**：谁长得跟中心句最像选谁；不求完全一样只求大致相同；关键词不扩大不缩小；「笼统的一定不如明确的，不选范围大，要选最精确的答案」。
**对策类主题词 = 对策+对象**（怎么做 + 为谁做）。
**找主题词走正路**：从文到句、从句到词，先凝练成一句话再凝练成词；直接看高频词是歪门邪道。

### 第三步：排除干扰 —— 逐项定位判死因

> 「你不能只把正确答案选出来，你还是要知道其他答案为什么不对。」
逐项回文段定位对应位置 → 判定死因（非重点/未提及/片面/偷换…）→ 逐个排掉。选不出时反向验证：「请问ABC有更好的吗？」

**验证原则**：正确答案代入文段逻辑要「讲得通」，否则这个题讲不通。
**复盘要求**：做完一定要思索这个题到底想表达什么意思，不要偷懒。
**自查（无日三省吾身）**：中心句找到了吗？主题词辨认出来了吗？干扰选项都排了吗？

### 对策类文段专章

1. 对策 = 必要条件 = 只有才（三者全等）。
2. 三种情况：①直接给对策（考最多）②反面提对策（假设做法+不好结果）③文段只有问题——选项有针对问题的对策照选，「这个不叫无中生有」；无对策选项才选问题表述。
3. **针对性（有A选A，无A选B）**：问题主体是谁对策就针对谁。
4. 内容大于形式：引导词只是提示，不是对策本身；内容都满足时再比形式（带引导词更优）。
5. 「因此我们需要…」= 结论+对策双buff叠buff，更重要。
6. 两个「要」连用：第一个是目标，第二个才是对策。
7. 对策过多提炼法：抓最前一点和最后一点。
8. 意义效果冒充对策：「换个马甲你就不认识了，是不是？」

## §二 细节判断题

**本质**：中心理解是找重点，细节判断是「判断对错有无」。
**做题顺序**（灵活）：文段晦涩/选项短 → 先看选项；通俗易懂 → 先读文段。「朝三暮四和暮四朝三的问题」。选非题先打叉做记号。

**基本解法**：选项与文段一一对应（大家来找茬）；抓选项「只有它才有」的特殊字词回文段定位。

**四类错误**：
1. **无中生有**：按话题层级判，不按字面（文段讲南极动物，出现企鹅不算；讲企鹅颜色才算）。
2. **偷换概念/概念混搭**：张冠李戴；把不相干的定语拼一起，「对戴错帽子了」。
3. **偷换逻辑三类**：强加因果、因果倒置（「谁养谁，方向是不是反了？」）、并列偷换（拔高一方为「核心/主体」不行）。注意：细节题不存在片面选项。
4. **与文意相悖**：方向说反。

**优先验证原则**（只优先看，不直接锁定）：选正确 → 先看温和表述（可能/也许）/合常识项；选错误 → 先看绝对表述（一定/都/唯一）/对比项/违常识项。
**考场止损**：锁定「错得最严重/对得最明显」的一个，其余不看直接走人；纠结项打问号。

## §三 干扰项全谱系（排除刀谱）

| 干扰模式 | 识别特征 | 判词话术 |
|---|---|---|
| 无主题词 | 缺核心话题 | 「没有主题词是一定不能选的」「就跟挠痒没挠到位一样」 |
| 非重点 | 对应举例/解释/转折前/结论前/背景/旧话题/意义效果 | 「虽然你对，但是不选」「板上钉钉的非重点」 |
| 片面 | 只对应文段一部分 | 「两个字片面送给你」「你只是做法之一」 |
| 无中生有 | 文段没提到 | 「文段从第一个字到最后一个字有提到吗？」 |
| 偷换概念 | 此人非彼人、此高质量非彼高质量 | 「此人非彼人」「换了个马甲你就不认识了？」 |
| 范围扩大/缩小 | 所有/部分失当 | 「范围扩大了，直接排掉」 |
| 与文意相悖 | 方向相反、恰是被反驳的观点 | 「那不就与作者的想法正好反了吗？」 |
| 程度失当 | 太绝对/太轻 | 「这个表达又有点太绝对了一些」 |
| 不明确/笼统 | 科学规划/神奇/你所不知道的 | 「什么叫科学规划？你告诉我什么意思嘛」「笼统的不如明确的」 |
| 同构选项 | 两项意思相同互相抵消 | 「你选A那D咋办？」直接干掉 |
| 无关对策 | 对策不对准问题主体 | 「你光靠个体去改变，能够应对吗？」 |
| 捡词陷阱 | 转折后随便拎一个词 | 「你得看重点的重点，重要性中的重要性」 |
| 双引号迷信 | 指望引号救场 | 「你加一万个双引号也没有用」 |

**出题人思维**：「你要带着这种预设去排除，这是一种上帝视角，这就是出题人思维。」「打分的权限不在你手上，在出题人手上。」并列文段必配片面项（常一前一后各一个）。
