# 语句表达系 SOP：后文推断 / 语句填空 / 语句排序（张弓方法）

> 「做后文推断就是先做一遍中心理解……没有比这句话更直接了吧？」
> 三题型在「找重点、找核心话题」这个第一步上没有任何区别，只是后续步骤不同。

## §一 后文推断题（接语选择题）

**识别**：提问含「接下来」三字；或提问含「开头/引言/序言/前言」四词之一（该段是文章引言）。「摘要」不是后文推断。
**做题顺序**：文段内容 → 选项，不能先看选项。

**三刀排除（有且只有三个维度）**：
1. **第一刀·核心话题一票否决**：先做一遍中心理解找核心话题；选项没有核心话题直接干掉——「入不了我的法眼」「就好比你写作文写离题了」。若只剩一个选项含核心话题，直接选定，「哪怕它重复了也得选它」。
2. **第二刀·讲过的不选**（有边界）：具体论述过的非重点内容不能选。两个豁免：①中心句内容不算重复（「这是考试的规矩」）；②问题除外（提出过的问题不会再讲，要分析或解决）。
3. **第三刀·比紧密**：多个都合格时，「谁跟他挨得最近我优先考虑谁」。紧密=长得像中心句/话题接近 + 叙述顺序靠前（提问题后先分析原因再给对策；原因分析过就只剩对策）。此时不考虑优选对策，只看谁挨得近。

**答案构成定律**：「文段提到的核心话题，再加一点文段没有讲过的新内容。」
**结构规律**：70%以上是分总结构，重点多在后半部分（早年「先看尾句」的原理，但现在也可能是总分，不能机械只看尾句）。
**不用无中生有排除**：「后文推断题不存在严格意义上的无中生有」，正确答案本就可带新内容。
**「决定了」判读**：A决定了B → 把A当重点，「理解为对策关系，不要理解为因果关系」。

## §二 语句填空题

**两大原则**：话题一致 + 衔接得当（读起来通顺不割裂）。
**由近到远**：横线是分句（后跟逗号）→ 优先句内衔接；是完整语句 → 看句子间关联。

**按位置定策略**：
| 横线位置 | 策略 |
|---|---|
| 结尾 | 总结前文或提对策，「横线所在句起到中心句的作用」，没有新东西。「别闹别闹，这是考试的规矩。」 |
| 开头 | 概括后文（总分，70%以上）或话题引入；优先选概括的，无概括项次选引入 |
| 中间 | 承上启下，优先选上下话题都提到的 |

**补丁·主题词位置**：把横线所在句当完整对象——主题词已在该句给定部分出现，横线可不重复；整句都没有，横线必须带主题词。词重复问题不大，通顺即可。
**陷阱**：「读起来顺」≠正确——「它看上去似乎很有道理，但跟前面衔接不当」「不搭嘎」，必须扣前文话题。

## §三 语句排序题

> 「内心深处先建立一个二+三。」

### 两大原则（磨刀环节）
1. **从选项差别入手**：「排序题一定不是直接把文段全读完」「一定要落脚在选项的差别。」
2. **排除法解题**：先知道哪些不对，剩下的就是答案。「就像断案，把所有不可能去掉，剩下的就是可能的。」排除角度**有且仅有两个**：①不符合先后关系；②不符合紧密相连。

### 先后顺序判断（行文逻辑4条 + 日常逻辑2条）
**行文逻辑**：
1. 先观点再解释：「越简略概括越在前，越详细具体越在后」。例外：概括句带明确结论词（因此/总之/总而言之）才可放后——「你没有因此我就默认你在前面了」。
2. 先下定义/引出话题，再展开。
3. 先提问再回答。
4. 先问题再对策（此问题非彼问题：疑问 vs 消极问题）。
**日常逻辑**：
5. 时间顺序（先唐再宋；话题一致前提下；「会倒叙吗？基本不会」）。
6. 事情发展脉络（先目标再实现，先笔试再面试再政审）。

### 紧密相连（三线索 + 一补充，全部「往前找」）
1. **指代词**（这/那/他/其/该）→ 往前找指代对象，注意单复数；前面那句也有指代词，「那就不排嘛，保留嘛」。
2. **关联词**（只考转折和并列）→ 转折考点是「话题相关且语义相反」；「转折之后是重点在排序题里没用，这不是做中心理解题」。并列要求话题强相关。
3. **看例子**（比如/例如/就像）→ 往前找一致的观点。
4. （补充）**特殊信息捆绑**：六句中「有且只有两句提到某信息」可酌情捆绑——「没有那么靠谱」，真没辙了才用。

### 三个步骤
1. **看首句**（从选项出发）：三类非首句特征一票否决，无需比较：①指代不清的指代词（注意：指代对象在本句出现就可以做首句）；②关联词后半段单独出现（所以/也/仍然/则/的确——「你能一上来就'的确'吗？」）；③明确举例标志。判断不出来不硬判断，进第二步。
2. **选思路**（两条路不分先后）：选项剩≥3个且文段有明显线索 → 从文段找线索回选项定位；线索不明显或只剩两选项 → 从选项找差异，**优先看首尾句**（「只用知道高考结束之后谁分最高就行了」）。
3. **验证**：绝大多数题不需要验证（太费时间）；仅一步到位/内心发慌时做；**验证逻辑性，不验通顺性**——「正确答案读起来也不通顺」。

### 心法
- 「做排序题，最怕什么呢？感觉。」「哪怕做错了没关系，你的每一步都有根据。」
- 死路即换路：「不要在一根树上吊死了，赶紧找别的路走嘛。」
- 「我们只能顾一般，不能顾特殊」「不要因噎废食，不要因个别题推翻方法」。
- 「老师没讲过的方法不要用——我没教过，说明不好用啊。」
- 「中心理解做的好，这个题自然做的好」，排序题不值得投入过多学习重心。

## §四 通用心法（三题型共用）

- 读不懂找高频词：「总有两个词在反复出现」。
- 「你的要求要放粗糙一点，不要那么的死板。」
- 细节题两难：「谁脑补更严重我选谁。」
- 「把握原则，灵活变通——唉，我觉得我总结的特别好啊。」
